# Character Design Guide
## Bubrolinguo

**Version:** 1.0
**Last Updated:** 2025-11-21

---

## Overview

Characters are the heart of Bubrolinguo's engagement strategy. Like Duolingo's Duo, our characters will guide users through their learning journey, provide encouragement, and create emotional connections that drive retention.

---

## Character Design Philosophy

### Core Principles

1. **Diverse Representation**: Characters reflect different ages, backgrounds, and personalities
2. **Cultural Authenticity**: Characters embody Polish culture and values
3. **Relatable Personalities**: Users can identify with different characters
4. **Consistent Voice**: Each character has distinct speech patterns and vocabulary
5. **Educational Purpose**: Characters teach through their dialogue and interactions

### Character Roles

- **Guide**: Introduces concepts, provides tips
- **Practice Partner**: Conversation practice scenarios
- **Motivator**: Encouragement, celebrating achievements
- **Cultural Ambassador**: Shares Polish culture and customs

## Visual Design Specifications

### Art Style

**Overall Aesthetic:**
- Modern, friendly illustration style
- Slightly stylized but recognizable
- Warm and inviting
- Culturally authentic details
- Consistent across all characters

**Technical Requirements:**
- Vector graphics (SVG) for scalability
- Multiple expressions per character (happy, encouraging, thinking, celebrating, concerned)
- Multiple poses (neutral, pointing, gesturing, active)
- Seasonal variations (optional, future)
- Outfit variations (optional, future)

### Character Specifications

**Deliverables per Character:**
- **Portrait**: Full face, neutral expression (256x256px, 512x512px)
- **Full Body**: Standing pose (512x1024px)
- **Expressions**: 5-8 variations (happy, sad, excited, thinking, surprised, encouraging, celebrating)
- **Poses**: 3-5 variations (pointing, gesturing, holding objects)
- **Animations** (future): Simple movements (blinking, nodding, waving)

**File Formats:**
- Master: Adobe Illustrator / Figma
- Export: SVG for web, PNG sets for mobile (1x, 2x, 3x)

### Style Guide

**Character Proportions:**
- Slightly stylized (not realistic)
- 5-6 heads tall (cute but adult)
- Diverse body types
- Expressive faces

**Color Palette:**
- Each character has signature colors
- Overall warm, friendly palette
- Accessible contrast ratios
- Consistent shading style

**Polish Cultural Elements:**
- Folk patterns (Zofia, Staszek)
- Modern Polish fashion (Jakub, Ania, Kasia)
- Authentic settings and props
- National colors tastefully incorporated

## Voice Production

### Voice Acting Requirements

**Recording Specifications:**
- **Format**: WAV, 48kHz, 24-bit
- **Environment**: Professional studio, soundproof
- **Equipment**: High-quality condenser microphone
- **Processing**: Light processing, natural sound

**Content to Record per Character:**
- **Lesson Intros/Outros**: 50-100 lines
- **Encouragement Phrases**: 30-50 lines
  - "Great job!"
  - "Try again!"
  - "You're doing well!"
  - "Keep going!"
- **Tips and Hints**: 30-50 lines
- **Conversation Scenarios**: 100-200 lines per character
- **Character-Specific Content**: 50-100 lines

**Total**: ~300-500 lines per character × 6 characters = 1,800-3,000 lines

**Voice Direction:**
- Natural, conversational delivery
- Clear enunciation for learners
- Appropriate emotion for context
- Consistent energy across sessions
- Variations for repeated phrases (avoid robot-feel)

### Voice Casting

**Casting Process:**
1. Post casting call in Poland (Warsaw, Kraków, Poznań)
2. Request audition samples (2-3 lines per character)
3. Shortlist 2-3 actors per character
4. Test recordings with target users
5. Select final actors
6. Long-term contracts (for consistency)

**Budget per Character:**
- Auditions: $500
- Recording session: $1,000-2,000 (full character, 300-500 lines)
- Studio time: Included or $500
- Editing/mastering: $500-1,000
- **Total per character**: $2,500-4,000
- **Total for 6 characters**: $15,000-24,000

### Voice Integration

**Technical Implementation:**
- Audio files CDN-hosted
- Compressed MP3 (96kbps for speech clarity)
- Lazy loading (fetch when needed)
- Cache on device
- Fallback: Text-only if audio fails

**User Controls:**
- Mute character voices
- Adjust volume separately from other audio
- Subtitle option (always available)

## Character Interaction System

### Dialogue System

**Dynamic Dialogue:**
- Character responses vary based on:
  - User's current level
  - Lesson context
  - Recent performance (struggling vs. excelling)
  - Time of day
  - User's streak status

**Example Logic:**
```
If user.streak >= 7:
  Zofia: "Seven days in a row! I'm so proud of you, kochanie!"
Else if user.struggles_with("genitive"):
  Piotr: "Let's focus on the genitive case today. You've got this."
Else if time_of_day == "evening":
  Ania: "Late night study session? Me too! Let's learn together."
```

### Character Preferences (Future)

**Allow users to:**
- Select favorite character (appears more often)
- Customize which characters appear in lessons
- Collect character stickers/badges
- Unlock special character content
